# Locadora de Veículos

Este é um sistema simples de locadora de veículos que permite calcular o valor estimado de aluguel de carros e visualizar os veículos cadastrados. O projeto foi desenvolvido com HTML e CSS.

### - Funcionalidades:
  
Cálculo de Previsão de Aluguel:
O usuário pode inserir o tipo de veículo e a quantidade de dias de locação para calcular o valor total.

Cadastro de Veículos:
A página exibe uma lista de veículos cadastrados com detalhes como tipo, modelo, placa e status.
